# TSM

Lecture notes and planning documents for the co-listed TSM 098–099 course.

- `index.html` is the table of contents for the browser edition.
- `lessons/` contains one HTML file for each of the 37 topics.
- `source-documents/` retains the Unit 1 Word document because its earlier Topic 1 lesson contains multiplication-fact guidance absent from the HTML. Units 2–5 were removed after comparing all 37 topics; Topics 2–37 match in content.
- `planning/` contains the co-listed course schedule.
- `specifications/` contains the lecture-note and test specifications.

The HTML notes are the maintained lecture-note source and include 208 click-to-reveal worked solutions. Each hidden solution preserves its natural height, providing a work area sized to the amount of solution content. Mathematical notation is rendered with MathJax when the pages are viewed online.

Edit lecture notes directly in `lessons/`. The retained Unit 1 Word document is a reference, not a second source to keep synchronized.
