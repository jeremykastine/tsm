Topic 5: Evaluating Square Roots

Assigned to: TSM 098 and TSM 099

Overview

This topic evaluates square roots when the radicand is a perfect square and distinguishes real square roots from square roots of negative numbers.

Key definitions

Square root: a number that produces the radicand when multiplied by itself. Radicand: the expression beneath a radical sign. Perfect square: the square of an integer. Imaginary unit: i, defined by i squared equals negative 1.

Compare and contrast the following problems, then complete each one.

Evaluate \(\sqrt{36}\), \(\sqrt{81}\), \(\sqrt{- 25}\), and \(\sqrt{- 121}\). Then explain why \(\sqrt{9} = 3\) but the equation \(x^{2} = 9\) has two solutions.

The meaning of a square root

A square root reverses squaring. The principal square root of a nonnegative number is the nonnegative number whose square is the original number. For example, because \(7^{2} = 49\),

\[\sqrt{49} = 7.\]

The radical symbol \(\sqrt{\phantom{x}}\) asks for the principal square root, so \(\sqrt{49}\) means \(7\), not \(\pm 7\). The symbol \(\pm\) appears later when we solve an equation such as \(x^{2} = 49\), because both \(7\) and \(- 7\) make that equation true.

Perfect-square radicands

When the number under the radical is a perfect square, evaluate the radical by finding the nonnegative number that squares to it.

\[\sqrt{100} = 10\quad\quad\text{because}\quad\quad 10^{2} = 100.\]

Useful perfect squares include \(0,1,4,9,16,25,36,49,64,81,100,121,144\), and \(169\). Learning these values makes later work with radicals and the quadratic formula much faster.

Negative radicands and imaginary numbers

No real number has a negative square. To evaluate a square root with a negative radicand, use the imaginary unit \(i\), defined by

\[i = \sqrt{- 1}\quad\quad\text{and therefore}\quad\quad i^{2} = - 1.\]

Separate the factor of \(- 1\), evaluate the remaining square root, and write \(i\) after the numerical coefficient.

\[\sqrt{- 16} = \sqrt{16}\sqrt{- 1} = 4i.\]

Similarly,

\[\sqrt{- 64} = 8i.\]

A common error is to write \(- 4\) for \(\sqrt{- 16}\). That cannot be correct because \(( - 4)^{2} = 16\), not \(- 16\).
