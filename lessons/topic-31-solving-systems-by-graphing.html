Topic 31: Solving Systems by Graphing

Assigned to: TSM 098 and TSM 099

Overview

This topic solves a system by graphing both lines and identifying the point, if any, that lies on both graphs.

Key definitions

System of equations: two or more equations considered together. Solution of a system: an ordered pair satisfying every equation. Consistent system: has at least one solution. Inconsistent system: has no solution.

Solve by graphing:

\[\begin{matrix} x - y & = - 1, \\ x + y & = 9. \end{matrix}\]

A system of equations asks for values that satisfy both equations at the same time. On a graph, the solution is the intersection point of the two lines.

Graph each equation accurately on the same coordinate plane. The lines intersect at \((4,5)\). Check the point in both original equations.

\[4 - 5 = - 1\]

\[4 + 5 = 9.\]

Because both statements are true, \((4,5)\) is the solution.

Accuracy matters

Use intercepts, slope-intercept form, or a table of ordered pairs to graph each line. Label the scale, draw straight lines through exact points, and mark the intersection clearly. If the apparent intersection is between grid points, estimate only when the directions allow an approximate answer.

Special cases

Parallel distinct lines never intersect, so the system has no solution. If both equations graph as the same line, every point on that line satisfies both equations, so the system has infinitely many solutions.

These cases can sometimes be recognized algebraically: parallel lines have equal slopes and different intercepts, while equivalent equations describe the same line.

Solve each system by graphing and verify the result algebraically: \(y = x + 2\) with \(y = - x + 6\); \(2x + y = 7\) with \(x - y = 2\); and \(y = 2x - 1\) with \(y = 2x + 4\).
