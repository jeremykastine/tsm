Topic 33: Solving Systems by Elimination and Substitution

Assigned to: TSM 098 and TSM 099

Overview

This topic solves systems algebraically by substitution or elimination and recognizes systems with one, no, or infinitely many solutions.

Key definitions

Substitution: replace a variable with an equivalent expression. Elimination: add or subtract equations so one variable cancels. Infinitely many solutions: both equations describe the same line. No solution: the equations describe distinct parallel lines.

Add the equations.

\[6x = 18\]

Elimination works well when coefficients of one variable are opposites. Solve

\[\begin{matrix} 2x + 3y & = 13, \\ 4x - 3y & = 5. \end{matrix}\]

\[x = 3.\]

Substitute into either original equation: \(2(3) + 3y = 13\), so \(y = 7/3\). The method is valid even when the solution is fractional, although assigned problems may be designed to produce whole-number coordinates.

Check an ordered pair first

An ordered pair solves a system only if it makes both equations true. Substitute its \(x\)- and \(y\)-coordinates into both equations before accepting it.

Substitution

Substitution works especially well when one equation already isolates a variable. Solve

\[\begin{matrix} y & = 2x + 1, \\ 3x + y & = 16. \end{matrix}\]

Replace \(y\) in the second equation with \(2x + 1\).

\[3x + (2x + 1) = 16\]

\[5x = 15\]

\[x = 3.\]

Substitute back into \(y = 2x + 1\): \(y = 7\). The solution is \((3,7)\), and it should be checked in both original equations.

Prepare a system when it is not already aligned

If coefficients are not opposites, multiply one or both complete equations by carefully chosen constants. Every term in an equation must be multiplied. Then add or subtract the equations to eliminate a variable.

Special systems

If substitution or elimination produces a false statement such as \(0 = 5\), the system has no solution. If it produces an identity such as \(0 = 0\), the equations represent the same line and the system has infinitely many solutions.

Solve and check: \(x + y = 9\) with \(x - y = 1\); \(y = 3x - 4\) with \(2x + y = 11\); and \(2x + 3y = 8\) with \(5x - 2y = 1\).
