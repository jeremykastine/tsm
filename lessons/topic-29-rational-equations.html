Topic 29: Rational Equations

Assigned to: TSM 099

Overview

This topic solves rational equations by stating restrictions, multiplying by the least common denominator, solving the resulting equation, and checking candidates.

Key definitions

Rational equation: an equation containing rational expressions. Restriction: a value that makes an original denominator 0. Extraneous solution: a result produced by transformed work that does not solve the original equation.

Solve

\[\frac{2}{x - 1} + \frac{1}{x + 1} = \frac{7}{x^{2} - 1}.\]

The restrictions are \(x \neq 1, - 1\), and the LCD is \((x - 1)(x + 1)\). Multiplying every term by the LCD gives

\[2(x + 1) + (x - 1) = 7.\]

\[3x + 1 = 7\]

\[x = 2.\]

Because \(2\) is allowable and makes the original equation true, it is the solution.

Restrictions come first

A rational equation contains one or more rational expressions. Before solving, find the values that make an original denominator zero. Those values are excluded. Then multiply every term by the least common denominator, solve the resulting equation, and check every proposed solution in the original equation.

Solve

\[\frac{x}{x - 2} = \frac{6}{x(x - 2)}.\]

The restrictions are \(x \neq 0,2\). Multiply by the LCD \(x(x - 2)\).

\[x^{2} = 6.\]

\[x = \pm \sqrt{6}.\]

Both values are allowable and both check in the original equation.

Extraneous solutions

Clearing denominators can produce a value that was excluded from the original equation. Solve

\[\frac{x + 1}{x - 3} = \frac{4}{x - 3}.\]

The restriction is \(x \neq 3\). Multiplying by \(x - 3\) gives \(x + 1 = 4\), so the transformed equation suggests \(x = 3\). But \(x = 3\) makes the original denominators zero. It is extraneous, and the original equation has no solution.

An extraneous solution is not a calculation failure. It is a candidate that must be rejected because it does not satisfy the original equation.

Factoring in rational equations

Factor denominators completely before building the LCD. Common methods include a greatest common factor, a difference of squares, and trinomial factoring. Do not cancel denominators term by term; multiply the entire equation by the LCD.

Solve and check: \(3/(x - 2) + 2/(x + 2) = 20/\left( x^{2} - 4 \right)\), \(1/x + 1/(x - 3) = 1\), and \((x + 5)/(x + 1) = 6/(x + 1)\).
